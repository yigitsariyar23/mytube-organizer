    No tracked videos yet

    Turn on the Track toggle on any channel (in its Variables cell, or via right-click) to pull that channel's latest uploads into this feed. Then click Refresh Stats to fetch them. Videos open on YouTube.

    Nothing saved yet

    On any YouTube page, right-click a video (or the watch page itself) and choose “Save to MyTube Watch Later.” Saved videos land here, where you can organize them into nested lists just like channels.

    Settings

    YouTube API

    Optional — enables video/subscriber counts and avatars. Free from Google Cloud Console.

    Fetches only missing avatars — skips counts and dates.

    Cross-device sync

    Syncs via a secret Gist. Use a token with only the gist scope. Never runs on its own — Upload and Download are manual, and each shows a review first. On a device that's behind, Download before you Upload.

    Languages

    Choose the languages you use. Only active languages appear in dashboard pickers and filters. Existing channel assignments are kept when a language is deactivated.

    Keyboard shortcuts

    Click a key to record a shortcut. Changes take effect when you save.

    Use letters, numbers, or punctuation, with optional modifiers. Escape cancels recording.

    Shortcuts stay on this device. Key labels use US keyboard positions; you can record the physical keys you prefer.
